# Security

Never commit passwords, API keys, passport scans, private keys, recovery codes, session cookies, or other credentials.

Use GitHub Actions Secrets for runtime credentials. Keep application documents outside the public repository.

Report security issues privately through the repository owner's GitHub contact path rather than opening a public issue with sensitive details.

The system deliberately pauses for CAPTCHA, MFA, signatures, payments, legal declarations, identity-sensitive uploads, and unknown applicant facts.
